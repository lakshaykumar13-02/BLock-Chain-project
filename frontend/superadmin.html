🛡️ Role-Based Authorization Guardrails

  • SUPER_ADMIN (Platform Owner)

    Full administrator lifecycle governance. Denied direct access to company evidence files and operational cases to preserve tenant boundary.

  • ADMIN (Operational Authority)

    Case creation, evidence custody transfers, PDF forensic reports, blockchain anchoring. Strictly denied all Super Admin account-management APIs (HTTP 403).

  • INVESTIGATOR (Forensic Field Officer)

    Custody updates, hash verification, permitted evidence inspection. Denied administrative configuration and Super Admin endpoints (HTTP 403).

🔒 Active Security Controls & Protections

⚡ Real-Time Session Invalidation

Tokens include an issued-at (iat) timestamp. Deactivating or resetting an admin account immediately invalidates all active JWT tokens on their next request.

🛡️ Anti-Lockout Protection

The backend strictly rejects deactivation or removal of the last active Super Admin with HTTP 400 Bad Request, guaranteeing console survivability.

⚖️ Evidentiary Integrity Preservation

When an administrator is removed, historical evidence records, SHA-256 hashes, and chain-of-custody signatures are retained permanently to ensure legal admissible integrity.
